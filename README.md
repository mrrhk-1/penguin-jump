# 🐧 Penguin Jump

A browser-based endless runner game where a penguin jumps over ice obstacles.

## 🎮 How to Play
- Press **SPACE** or **↑** or **Click** to jump
- Avoid the ice block 🧊
- Score increases every obstacle you dodge
- Speed increases every 5 points

## ✨ Features
- Smooth 60 FPS animation (`requestAnimationFrame`)
- Persistent high score (`localStorage`)
- Progressive difficulty
- Keyboard + mouse controls

## 🛠 Tech Stack
HTML5 · CSS3 · Vanilla JavaScript · GitHub Actions · GitHub Pages
